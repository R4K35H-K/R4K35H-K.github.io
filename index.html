Featured Project

Master Stego Suite

A powerful, high-performance Image Steganography & Steganalysis application built with Python and CustomTkinter. Implements LSB embedding, a Randomized Scattering engine using password-seeded PRNGs, AES-256 encryption, and a full Steganalysis Testbench featuring Chi-Square attack plotting and PoV histogram analysis.
