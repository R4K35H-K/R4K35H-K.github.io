## About

This repository hosts the source code for my personal academic portfolio website, deployed via [GitHub Pages](https://pages.github.com/). It showcases my research in **Robust JPEG Steganography**, **Steganalysis**, and **Multimedia Security** for social networking platforms.

## Research Focus

My work centers on developing highly efficient, novel secret information concealment schemes that are resilient to aggressive recompression on platforms like X (Twitter), LinkedIn, WhatsApp, and Facebook. Key contributions include four novel steganographic schemes: **SARAS**, **MRAS**, **CEDAR**, and **DRAS**.
